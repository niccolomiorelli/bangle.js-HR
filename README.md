Heart rate algorithms for Bangle.js
==================================

This repository contains a collection of heart rate estimation algorithms developed for Bangle.js recordings. They are extended to work also on Empatica EmbracePlus recordings ("_emp" folders).
The software processes raw input signals, including photoplethysmography (PPG) and accelerometer data, and generates output files containing the heart rate estimates produced by the implemented algorithms together with the available reference signals.

## Compile:

```bash
cmake --build build
```

# Run:

```bash
.\build\Debug\heartrate.exe INPUT_Dataset OUTPUT_Dataset
```
,where:
 - INPUT_Dataset is the path to the input dataset directory
 - OUTPUT_Dataset is the path to the directory where the output files will be saved

If you are using Visual Studio Code, the build and execution processes can also be performed through the dedicated run task defined in tasks.json or run.bat.

# Input Data Format

Each input file is expected to contain the following columns:

 ms,ms (abs),PPG,ACCx,ACCy,ACCz,GT_bangle,GT_polar(,GT_cosmed)

,where:
 ms: relative timestamp in milliseconds
 ms (abs): absolute timestamp in milliseconds
 PPG: photoplethysmographic signal
 ACCx, ACCy, ACCz: accelerometer signals along the three axes
 GT_bangle: reference heart rate from the Bangle device (or from the primary smartwatch used for acquisition)
 GT_polar: reference heart rate from the Polar device (or from an external reference system)
 GT_cosmed: optional reference heart rate from the COSMED system (or from an additional secondary reference system)

 # Output Data Format
 
 Each output file contains the following columns:

 time,time (abs),Dummy,Espruino,FFT,Autocorrelation,Oxford,PanTompkins,Autocorrelation2,FFT2,TRUST_PPG1,TRUST_PPG2,TRUST_PPG3,TRUST_PPG4,GT_Bangle,GT_polar(,GT_cosmed)

 These columns include the time information, the heart rate estimates generated by the implemented algorithms, and the available ground truth signals.

 # Implemented Algorithms

The repository currently includes the following algorithms:

 - Dummy
 - Espruino
 - FFT
 - Autocorrelation
 - Oxford
 - PanTompkins
 - Autocorrelation2
 - FFT2
 - TRUST_PPG1 (for Bangle.js and for Empatica)
 - TRUST_PPG2 (for Bangle.js and for Empatica)
 - TRUST_PPG3 (for Bangle.js and for Empatica)
 - TRUST_PPG4 (for Bangle.js and for Empatica)

# Notes
Make sure that the project has already been configured with CMake and that the build directory exists.
On Windows, the executable is expected to be generated in:
.\build\Debug\heartrate.exe

Update the input and output paths according to your local folder structure before running the executable.

The structure of both the input and output files can be easily modified by editing the `main.c` file. In particular, it is possible to select only the algorithms of interest, as well as to add or remove reference signals from the input columns.
